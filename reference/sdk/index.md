# SDK reference

Source: https://docs.mapx.at/reference/sdk/

> Type reference of mapx-gl: functions, controls, options and response types.

The complete type reference of [`mapx-gl`](https://docs.mapx.at/guides/sdk/index.md), generated from the TypeScript sources with TypeDoc. Install and first steps: [SDK mapx-gl](https://docs.mapx.at/guides/sdk/index.md). All requests go to `https://api.mapx.at/v1`; errors are thrown as [`MapxError`](https://docs.mapx.at/reference/sdk/classes/mapxerror.md).
