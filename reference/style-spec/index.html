Style specification

Style specification

Style IDs

IDLook
streets, streets-dawn, streets-dusk, streets-nightBase map in four light moods
satellite, satellite-streetsOrthophoto, optionally with roads and labels
outdoorsContours, hillshade, trails
traffic-dayBase map with the traffic layer

Styles are MapLibre style documents (version 8) at https://api.mapx.at/v1/styles/{id}. Their metadata keys are mapx:style and mapx:api_style. See the Styles API.

Layers of streets

Every layer of streets with its fields. For fields with a closed list, all values are listed. Layer names end in _a (polygon), _l (line) or _p (point).

Common fields: min_zoom is the first zoom level at which a feature is intended to be shown (use it in filters for an even density); sort_rank orders features within a layer (smaller = more important or drawn first).
