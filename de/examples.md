# Beispiele

Sechsundzwanzig lauffähige Beispiele mit MapLibre GL JS und dem SDK mapx-gl: Karten, Suche, Navigation, Höhe, ÖV, Verkehr, statische Bilder, Grundstücke, Wetter.

Jedes Beispiel läuft live auf der Seite, zeigt den vollständigen Code und eine einzelne HTML-Datei zum Kopieren. Grundlage sind MapLibre GL JS (4.7.1) mit pmtiles (3.2.1), ohne Schlüssel und ohne Build. Nach Produkt filtern:

## Hinweise

- Alle Daten stammen aus amtlichen Quellen, keine OSM-Daten. Attribution: [Lizenz](/de/reference/attribution/).
- Alle Beispiele rufen die Endpunkte unter `https://api.mapx.at/v1/` ohne Zugangstoken auf.
- Beispiele mit SDK-Kennzeichnung nutzen [`mapx-gl`](/de/guides/sdk/).
