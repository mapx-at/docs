# Was ist mapx

Karten und Location-APIs für Österreich, ausschließlich auf offiziellen Open Data.

mapx ist eine Sammlung von Karten und Location-APIs für Österreich. Alle Daten stammen aus offiziellen offenen Quellen (BEV, GIP.at, ASFINAG, GeoSphere Austria, ÖBB und weitere). Deshalb gibt es keine nutzungsabhängigen Preise, kein Konto und keinen Key.

| Produkt | Inhalt | Einstieg |
|---|---|---|
| Karten | Vektor- und Raster-Tiles, fertige Styles (`streets`, `satellite`, `outdoors`), TileJSON | [Karten](/de/guides/maps/) |
| Suche | Geocoding, Type-ahead-Search-Box, Adress-Autofill und Validierung | [Suche](/de/guides/search/) |
| Navigation | Routen für Auto, Lkw, Rad und zu Fuß, Isochronen, Matrizen, Map Matching, Maut | [Navigation](/de/guides/navigation/) |
| Verkehr | Störungsmeldungen, Tempolimits auf Autobahnen, eine Verkehrsebene | [Verkehr](/de/guides/traffic/) |
| Transit | Verbindungen im öffentlichen Verkehr, Haltestellen, Abfahrten | [Transit](/de/guides/transit/) |
| Static Images | PNG- oder WebP-Karten mit Pins, Pfaden und GeoJSON | [Static Images](/de/guides/static-images/) |
| Höhen und Gelände | Höhen, Höhenprofile, Gelände- und Oberflächenmodelle | [Höhen](/de/guides/elevation/) |
| Grundstücke | Katastergrundstück mit Fläche und Nummer an jedem Punkt | [Grundstücke](/de/guides/parcels/) |

Die APIs folgen den Konventionen bekannter Web-Mapping-Dienste: gleiche URL-Formen, GeoJSON-Antworten und MapLibre-kompatible Styles. Bestehender Code für MapLibre, Leaflet oder OpenLayers braucht wenige Änderungen.
