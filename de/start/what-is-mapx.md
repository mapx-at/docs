# Was ist mapx? Karten-API für Österreich

Source: https://docs.mapx.at/de/start/what-is-mapx/

> mapx ist eine Sammlung von Karten- und Location-APIs für Österreich, ausschließlich auf amtlichen offenen Daten: Kacheln, Geocoding, Routing, Höhe, ÖV und mehr.

mapx ist eine Sammlung von Karten und Location-APIs für Österreich. Alle Daten stammen aus offiziellen offenen Quellen (BEV, GIP.at, ASFINAG, GeoSphere Austria, ÖBB und weitere). Deshalb gibt es keine nutzungsabhängigen Preise. Ein kostenloses Konto und ein API-Token sind nötig ([Zugang und Limits](https://docs.mapx.at/de/start/access-and-limits.md)).

| Produkt | Inhalt | Einstieg |
|---|---|---|
| Karten | Vektor- und Raster-Tiles, fertige Styles (`streets`, `satellite`, `outdoors`), TileJSON | [Karten](https://docs.mapx.at/de/guides/maps.md) |
| Suche | Geocoding, Type-ahead-Search-Box, Adress-Autofill und Validierung | [Suche](https://docs.mapx.at/de/guides/search.md) |
| Navigation | Routen für Auto, Lkw, Rad und zu Fuß, Isochronen, Matrizen, Map Matching, Maut | [Navigation](https://docs.mapx.at/de/guides/navigation.md) |
| Verkehr | Störungsmeldungen, Tempolimits auf Autobahnen, eine Verkehrsebene | [Verkehr](https://docs.mapx.at/de/guides/traffic.md) |
| Transit | Verbindungen im öffentlichen Verkehr, Haltestellen, Abfahrten | [Transit](https://docs.mapx.at/de/guides/transit.md) |
| Static Images | PNG- oder WebP-Karten mit Pins, Pfaden und GeoJSON | [Static Images](https://docs.mapx.at/de/guides/static-images.md) |
| Höhen und Gelände | Höhen, Höhenprofile, Gelände- und Oberflächenmodelle | [Höhen](https://docs.mapx.at/de/guides/elevation.md) |
| Grundstücke | Katastergrundstück mit Fläche und Nummer an jedem Punkt | [Grundstücke](https://docs.mapx.at/de/guides/parcels.md) |

Die APIs folgen den Konventionen bekannter Web-Mapping-Dienste: gleiche URL-Formen, GeoJSON-Antworten und MapLibre-kompatible Styles. Bestehender Code für MapLibre, Leaflet oder OpenLayers braucht wenige Änderungen.
