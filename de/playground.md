# Playground: die API im Browser ausprobieren

Source: https://docs.mapx.at/de/playground/

> Interaktive Playgrounds für jede mapx-API: Parameter ändern, Anfrage mit dem eigenen Token senden, Antwort ansehen und als curl, JavaScript oder Python kopieren.

Jede Seite der API-Referenz endet mit einem Playground: Operation wählen, Parameter ändern, Anfrage mit dem eigenen Token senden und den Aufruf als curl, JavaScript oder Python kopieren. Den Token gibt es unter [account.mapx.at](https://account.mapx.at) ([Zugang und Limits](https://docs.mapx.at/de/start/access-and-limits.md)).
