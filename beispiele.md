# Beispiele

Zwölf lauffähige Beispiele mit MapLibre GL JS: Karte, Gelände, Höhenprofil, Suche, Route, Isochrone, Kataster.

Jedes Beispiel läuft live auf der Seite, zeigt den vollständigen Code und eine einzelne HTML-Datei zum Kopieren. Grundlage ist MapLibre GL JS (4.7.1) mit pmtiles (3.2.1), ohne Schlüssel und ohne Build.


                        
## Hinweise

- Alle Daten stammen aus amtlichen Quellen, keine OSM-Daten. Attribution: [Lizenz](/lizenz/).
- Beispiele, die Endpunkte unter `/v1/` ansprechen, die noch ausgerollt werden, verwenden bis dahin die bestehenden Dienste. Das steht jeweils auf der Beispielseite unter *Stand der Endpunkte*.
