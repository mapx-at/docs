Search

Pick the endpoint by what the user does.

Task Endpoint
Convert a typed address or place to coordinates /v1/geocode
Show suggestions while the user types /v1/searchbox/suggest
Fill a postal address form /v1/autofill/suggest
Check an address /v1/address/validate
Find the address at a point /v1/reverse
Show places of a kind (pharmacy, station) /v1/searchbox/category/{category}

All data is official: the address register, place names, administrative boundaries and cadastre from BEV. Requests are in the search zone, 10 per second and need a token (Access and limits); curl samples send it as a header, browser samples as access_token.

Geocode an address

Section titled “Geocode an address”

Always pass types (address, street, locality, place, district, region, postcode, poi). Narrow the result with bbox=minlon,minlat,maxlon,maxlat or rank by distance with proximity=lon,lat.

Reverse geocode

Section titled “Reverse geocode”

Type-ahead search

Section titled “Type-ahead search”

Call suggest on every pause in typing (debounce 200 ms), then retrieve once for the chosen entry. Send the same session_token for both calls.

Suggestions carry a category (poi_category_ids, for example place_of_worship_church) and the administrative context. Cancel the previous request when a new key is typed (AbortController). Example: Search.

Places by category

Section titled “Places by category”

list/category returns all category IDs with localized names (language=de or en).

Address forms

Section titled “Address forms”

Autofill returns split fields that map to form inputs.

Validation checks what the user typed:

status is match, corrected, ambiguous (then candidates[]) or not_found. Abbreviations, umlauts and ß are understood. Use POST with JSON for structured input.

Batch

Section titled “Batch”

POST /v1/geocode/batch geocodes up to 1000 queries in one request (zone heavy, 30 per minute).
