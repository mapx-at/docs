Elevation and terrain

mapx has two height models of 1 m resolution (BEV, laser scanning): the terrain model dtm (bare ground) and the surface model dsm (including trees and buildings). Use dtm for gradients, profiles and trails, dsm for visibility and building heights.

Heights are in meters with 0.1 m steps. Outside the data area the value is null.

Elevation profile

Section titled “Elevation profile”

Up to 1024 samples along a line of 2 to 512 vertices. Example with a chart: Elevation profile. Routes already carry ascent and descent in routes[].summary; use annotations=elevation for a height per segment.

Read heights from tiles

Section titled “Read heights from tiles”

The tiles use the Terrain-RGB encoding: height = -10000 + (R * 65536 + G * 256 + B) * 0.1. Decode tiles yourself for bulk work, see Terrain-RGB. For single points the API is simpler.
