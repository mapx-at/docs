SDK helpers for the APIs

Every helper is a plain async function that returns typed JSON and throws a MapxError on failure. Coordinates are [lng, lat]. Pass signal (an AbortSignal) to cancel a request. All examples run in the browser console on any page that has loaded mapx (install).

Search and geocoding

Section titled “Search and geocoding”

Routing

Section titled “Routing”

exclude works for the driving profile only, truck only for driving-truck. Both are validated: a wrong combination throws a MapxError with code: "bad-request".

Parcels and tilequery

Section titled “Parcels and tilequery”

parcel(point, { dossier: true }) returns the dossier for every parcel at the point in one request.

Static image URL

Section titled “Static image URL”

staticImageUrl builds the URL without a request. Use it in <img>, e-mails and PDFs.

Use mapx.geojsonOverlay(feature) to draw a polygon (for example a parcel) with Simplestyle properties, and leave center and zoom out to fit the overlays (auto).

Other API host

Section titled “Other API host”

mapx.setApiBase("https://staging.example.com/v1") redirects all helpers, for tests or a mirror.
