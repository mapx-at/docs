# Basemap: layer reference

All 18 layers of the mapx basemap with every field and all possible values.

Every layer of [mapx-basis](/en/daten/basiskarte/) with its fields. For fields with a closed list, all values are listed. Layer names end in `_a` (polygon), `_l` (line) or `_p` (point).

Common fields: `min_zoom` is the first zoom level at which a feature is intended to be shown (use it in filters for an even density); `sort_rank` orders features within a layer (smaller = more important or drawn first).
