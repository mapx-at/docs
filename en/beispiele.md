# Examples

Thirteen runnable examples with MapLibre GL JS: map, terrain, elevation profile, search, route, isochrones, cadastre.

Each example runs live on the page, shows the complete code and a single HTML file to copy. The basis is MapLibre GL JS (4.7.1) with pmtiles (3.2.1), no key and no build.


                          
## Notes

- All data comes from official sources, no OSM data. Attribution: [License](/en/lizenz/).
- All examples call the endpoints under `https://api.mapx.at/v1/`, without an access token.
