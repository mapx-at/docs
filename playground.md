# Playground: try the API in the browser

Source: https://docs.mapx.at/playground/

> Interactive playgrounds for every mapx API: change parameters, send the request with your token and see the response, then copy it as curl, JavaScript or Python.

Every API reference page ends with a playground: pick an operation, change the parameters, send the request with your token and copy the call as curl, JavaScript or Python. You need a token from [account.mapx.at](https://account.mapx.at) ([Access and limits](https://docs.mapx.at/start/access-and-limits.md)).
