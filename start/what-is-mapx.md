# What is mapx

Maps and location APIs for Austria, built only on official open data.

mapx is a set of maps and location APIs for Austria. All data comes from official open sources (BEV, GIP.at, ASFINAG, GeoSphere Austria, ÖBB and others), so there is no usage-based pricing, no account and no key.

| Product | What you get | Start |
|---|---|---|
| Maps | Vector and raster tiles, ready-made styles (`streets`, `satellite`, `outdoors`), TileJSON | [Maps](/guides/maps/) |
| Search | Geocoding, type-ahead Search Box, address autofill and validation | [Search](/guides/search/) |
| Navigation | Routes for car, truck, bike and foot, isochrones, matrices, map matching, tolls | [Navigation](/guides/navigation/) |
| Traffic | Incident reports, motorway speed limits, a traffic layer | [Traffic](/guides/traffic/) |
| Transit | Public transport journeys, stops, departures | [Transit](/guides/transit/) |
| Static images | PNG or WebP maps with pins, paths and GeoJSON | [Static images](/guides/static-images/) |
| Elevation and terrain | Heights, elevation profiles, terrain and surface models | [Elevation](/guides/elevation/) |
| Parcels | Cadastral parcel with area and number at any point | [Parcels](/guides/parcels/) |

The APIs follow the conventions of well-known web mapping services: the same URL shapes, GeoJSON responses and MapLibre-compatible styles. Existing MapLibre, Leaflet or OpenLayers code needs few changes.
